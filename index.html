♞ Analyseur d'échecs

Analyse tes parties Chess.com avec Stockfish, directement dans ton navigateur.

    Comment ça marche ?

    1. Entre ton pseudo Chess.com pour afficher tes dernières parties (ou colle un PGN).
    2. Clique sur une partie : Stockfish l'analyse coup par coup, dans ton navigateur.
    3. Repère tes gaffes, erreurs et imprécisions, et découvre le meilleur coup à chaque fois.

    Utilise les flèches ← → du clavier pour naviguer dans la partie.

    Données : API publique Chess.com · Moteur : Stockfish.js (GPLv3) · Pièces : cburnett (CC BY-SA 3.0)
